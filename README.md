# Reflection That Lasts

An interactive workshop page on portfolio reflection, based on Chapters 2 and 3 of Jeff Zwiers' *Next Steps with Academic Conversations* (Stenhouse, 2019).

**Live page:** https://jayamohanj-cmd.github.io/Academic-Conversations---Art-Portfolio-Reflection-/

Open the live page, then scroll or use the left and right arrow keys to move between sections.

## What's inside

- An idea tower (Chapter 2: Building Ideas)
- A balance scale for weighing evidence (Chapter 3: Collaborative Arguments)
- A timed Think–Write–Talk–Rewrite routine for teachers to try
- The 25-minute student protocol
- A prompt deck for portfolio reflections
- Downloadable handouts (last section of the page)
